# 행복헌법 717 시민 페스타

제헌절(7/17)을 맞아 헌법 제10조 **행복추구권**을 청년의 언어로 다시 쓰는 인터랙티브 문화 페스타 랜딩 사이트.
카피: **"행복에도 헌법이 있다면?"**

- **주최** 이어온 · **주관** SSalty
- **일시** 2026. 7. 17(금)~18(토) 14:00–18:00
- **장소** 프레쉬엔지니어드 홍대점 / 서교플레이스(예정)
- **체험비** 5,000원 (현장 납부)

## 기술 스택
Next.js 15 (App Router) · Tailwind CSS v4 · Framer Motion · GSAP ScrollTrigger · Lenis

## 로컬 실행
```bash
cd site
npm install
npm run dev      # http://localhost:3000
npm run build    # 프로덕션 빌드
```

## Vercel 배포 (중요)
Next.js 앱은 **`site/` 하위 디렉토리**에 있습니다. Vercel 프로젝트 생성 시:

1. 이 저장소를 import
2. **Root Directory** 를 **`site`** 로 설정 (기본값 `.` 아님 — 반드시 변경)
3. Framework Preset: **Next.js** (자동 감지됨)
4. Build/Output 설정은 기본값 그대로 두면 됩니다

> ⚠️ Next.js는 **15.x** 로 고정되어 있습니다. 16으로 올리지 마세요.

### 커스텀 도메인 / OG
- 커스텀 도메인 사용 시 환경변수 `NEXT_PUBLIC_SITE_URL` (예: `https://행복헌법717.kr`) 을 지정하세요. 미지정 시 Vercel 프로덕션 도메인이 자동 사용됩니다.

## 주요 인터랙션
1. **자소 조립 인트로** — '행복/헌법' 대형 한글이 자소 단위로 조립
2. **나의 행복헌법 카드 생성** — 침해요소·필요한 것을 선택하면 개인 헌법 조항 카드를 실시간 생성하고 PNG로 저장
3. **저울·붓펜 스크롤 조립** — 스크롤에 따라 저울이 조립되고 붓펜이 꽂히며 배경이 네이비(법의 격식)→테라코타(행복의 온기)로 전이
